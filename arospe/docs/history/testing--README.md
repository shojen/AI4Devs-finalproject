_Previously: 2026-08-29 — Story 0020 (Shared media gallery modal — frontend): one widened pointer, no structural change. The **Frontend / Browser** entry now names story 0020's three source-verified tooling findings, because each one changes what a QA author should even attempt: a bare `->wait(n)` gets none of an assertion's retry machinery **and** races the plugin's own 5000 ms ceiling, so widening one is a fix that makes things worse; a real file upload cannot be driven through `visit()` at all here (two independent causes, one of them a literal `[], // @TODO files...` in the plugin's HTTP driver), so upload-completion coverage belongs to Feature tests permanently and a browser test that needs it is honestly `->skip()`'d; and a page mounting one component twice duplicates every `data-test` hook, which fails selectively — strict-mode violations on single-element assertions, silent tolerance from `assertSee()`. **Verified as unchanged rather than assumed:** the four authorization layers (story 0020's Phase 4 F-1 is a new *rule* about layer three on a routeless component, not a fifth layer — see [security/livewire-authorization.md](../security/livewire-authorization/entry-point-and-method-gates.md#the-routeless-case-a-component-with-no-route-has-no-per-request-backstop-at-all)), the QA section, the backend section, the CI entry and the worktree-databases entry; the story adds ~40 tests across `tests/Feature/Media/`, `tests/Feature/Dev/` and the new `tests/Browser/Media/`, and changes no command, threshold or database strategy._

_Previously: 2026-08-27 — Story 0019 (Media Library upload and conversions — backend): two pointers, no structural change. The **CI** entry now names `extensions: imagick` and the rejected `->skip()` alternative, and **Related** gains [security/image-upload-processing.md](../security/image-upload-processing.md) — deliberately filed there rather than under a new Security heading, since this index has never carried one and inventing a section for a single page would be worse than a pointer.
